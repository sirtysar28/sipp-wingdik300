📌 Pengenalan

Apa itu SIPP?

SIPP (Sistem Informasi Penilaian Prestasi) adalah aplikasi berbasis web yang dirancang untuk mengelola seluruh proses penilaian siswa didik militer — dari data master hingga cetak laporan akhir pendidikan.

📊
Dashboard Monitoring
Rata-rata NPA/NPK/NPS/NPP, podium Top 3, ranking 4–10, dan distribusi nilai
📚
Nilai Akademik (NPA)
Input nilai per mata pelajaran, hitung NPA otomatis dengan bobot & harga nilai
🧠
Nilai Kepribadian (NPK)
Aspek kepribadian dengan skala BS/B/C/K/KS per periode, grafik tren & radar
🏃
Nilai Samapta (NPS)
5 field manual per putaran (Jarak Lari, Garjas A, Garjas B, Nilai Akhir, Konversi)
🏆
Kompilasi Nilai (NPP)
NPP dihitung live dari NPA + NPK + NPS dengan bobot — ranking & predikat
🖨️
Cetak Laporan
Cetak laporan individu & keseluruhan dengan penandatangan resmi
ℹ️
4 Komponen Penilaian: SIPP mengelola 4 jenis nilai utama:
NPA = Nilai Prestasi Akademik  |  NPK = Nilai Prestasi Kepribadian  |  NPS = Nilai Prestasi Samapta  |  NPP = Nilai Prestasi Pendidikan (Kompilasi)
🔐 Login

Login & Akses Sistem

Hanya pengguna terdaftar yang memiliki akun login. Akun dibuat oleh Super Admin atau Opsdik melalui menu Manage User.

Cara Login

1

Buka halaman login

Ketik alamat SIPP di browser, sistem akan otomatis redirect ke halaman login.

2

Masukkan email dan password

Gunakan kredensial yang diberikan oleh Super Admin / Opsdik.

3

Klik tombol "Masuk"

Jika berhasil, sistem mengarahkan ke Dashboard sesuai peran pengguna.

4

Klik "Keluar" untuk logout

Tombol Keluar ada di bagian bawah sidebar kiri (sebelah info user).

⚠️
Keamanan akun! Segera ganti password jika diberikan password default. Hubungi Super Admin / Opsdik untuk reset password jika lupa.

📊 Dashboard

Dashboard

Dashboard menampilkan ringkasan status penilaian angkatan secara real-time: rata-rata setiap komponen nilai, podium Top 3 NPP, ranking 4–10, dan distribusi nilai akhir. Dapat diakses oleh seluruh role yang login.

Komponen Dashboard

📈
8 Kartu Statistik
Total Peserta, Rata-rata NPA, NPK, NPS, NPP, NPP Tertinggi, Terendah, & jumlah di bawah rata-rata
🏆
Podium Top 3 NPP
Visualisasi peringkat 1, 2, 3 dari kompilasi nilai akhir (dihitung live)
🔢
Ranking 4 – 10
Tabel peringkat 4 sampai 10 beserta NPP masing-masing peserta
📊
Distribusi NPP
Histogram sebaran nilai akhir (≥85, 80–84, 75–79, 70–74, 65–69, <65)

Cara Menggunakan

1

Pilih Sekolah & Angkatan

Gunakan dropdown filter di atas dashboard. Data otomatis berubah saat filter dipilih.

2

Pantau statistik & podium

Rata-rata NPA/NPK/NPS/NPP dan Top 3 dihitung langsung dari data sumber.

3

Aktifkan periode kepribadian

Jika ada periode yang belum aktif, klik tombol "Aktifkan" pada periode yang sesuai.

💡
Dihitung live: Podium, ranking, dan NPP dihitung langsung dari NPA + NPK (rata-rata semua periode) + NPS menggunakan bobot kompilasi. Tidak perlu proses kompilasi manual agar ranking muncul.

5

📚 NPA

Report NPA (Akademik)

Report NPA adalah pusat pengelolaan nilai akademik. Selain melihat rekap, Anda juga menginput nilai dari halaman ini. Diakses oleh Super Admin, Opsdik, dan Kepala Sekolah.

Aktivitas di Report NPA

📥
Impor Excel
Upload nilai akademik dari file Excel per angkatan
✏️
Input Manual
Pilih peserta, isi nilai per mata pelajaran
🔀
Edit Nilai
Ubah nilai yang sudah diinput sebelumnya
🔄
Recalculate
Hitung ulang semua NPA (misal setelah ubah bobot mapel)
🖨️
Cetak NPA
Cetak rekap NPA angkatan ke PDF
⬇️
Ekspor
Download laporan NPA dalam format Excel

Cara Input Manual NPA

1

Pilih Sekolah & Angkatan

Gunakan dropdown filter di halaman Report NPA.

2

Klik "Input Manual"

Pilih peserta dari dropdown.

3

Isi nilai per mata pelajaran

Mata pelajaran otomatis tampil sesuai Sekolah angkatan.

4

Klik Simpan

NPA dihitung otomatis: NPA = Σ (nilai × bobot) / Σ bobot

Rumus NPA
NPA = Σ (Nilai Mapel × Bobot) ÷ Σ Bobot
Bobot diambil dari data Mata Pelajaran per Sekolah. Contoh: Matematika 80 (bobot 3) + Fisika 75 (bobot 2) = (80×3 + 75×2) / 5 = 78
📖 Mata Pelajaran

Mata Pelajaran

Mata pelajaran dikelola per Sekolah dan dapat dipetakan ke banyak sekolah (many-to-many). Menu ini tersarang di bawah Report NPA. Diakses oleh Super Admin, Opsdik, dan Kepala Sekolah. Setiap mapel memiliki atribut: JP (Jam Pelajaran), Bobot, dan Harga Nilai yang dipakai bersama antar sekolah.

1

Pilih Sekolah

Dropdown filter di atas. Mapel ditampilkan sesuai Sekolah yang dipilih, beserta Total Bobot aktif.

2

Tambah mapel baru

Klik "Tambah Baru", isi Nama, Kode, JP, Bobot, dan Harga Nilai. Klik Simpan.

3

Petakan mapel yang sudah ada

Pilih mapel dari sekolah lain lalu klik "Petakan ke Sekolah Ini" agar tidak perlu input dobel.

4

Load Template / Duplikasi

Gunakan "Load Template" untuk memuat mapel default, atau "Duplikasi" untuk menyalin mapel dari sekolah lain sekaligus.

5

Atur urutan & status aktif

Urutan tampil & status aktif diatur per-sekolah. Bobot & harga nilai milik mapel (dipakai bersama).

✅
Many-to-many: Satu mata pelajaran bisa dipakai banyak sekolah. Mengubah bobot/harga nilai pada mapel akan berlaku di semua sekolah yang memetakannya.
🧠 NPK

Report NPK (Kepribadian)

Report NPK sekaligus pusat input nilai kepribadian. Menampilkan rekap & analisis lengkap: histori per periode, grafik tren, radar aspek, statistik, dan tombol input per peserta. Diakses oleh Super Admin, Opsdik, dan Danflight.

Skala Penilaian

BS
Baik Sekali
+0.5 poin
B
Baik
+0.25 poin
C
Cukup
0 poin
K
Kurang
-0.25 poin
KS
Kurang Sekali
-0.5 poin
Formula Nilai Kepribadian
NPK = 75 + Σ Poin Aspek
Nilai awal 75 · Maksimum 80 (semua BS) · Minimum 70 (semua KS)

🏃 NPS

Report NPS (Samapta)

Modul Samapta menggunakan versi sederhana: 5 field manual tanpa rumus otomatis. Input dibedakan per putaran. Diakses oleh Super Admin, Opsdik, dan Binjaswing.

5 Field Input Samapta

KolomKeterangan
Jarak Lari (meter)Hasil jarak tempuh lari 12 menit
Nilai Lari (Garjas A)Nilai untuk hasil lari
Garjas BNilai komponen Garjas B
Nilai AkhirNilai akhir samapta (NPS) untuk putaran ini
Nilai KonversiNilai hasil konversi (bila diperlukan)
⚠️
Tanpa rumus otomatis: Seluruh nilai diisi manual. Tidak ada perhitungan TSC/Garjas otomatis. Pastikan nilai akhir & konversi sudah benar saat input.

Cara Input Manual NPS

1

Buka menu Report NPS

Pilih Sekolah, Angkatan, dan Putaran.

2

Klik "Input Manual"

Pilih peserta, lalu isi 5 field (Jarak Lari, Garjas A, Garjas B, Nilai Akhir, Nilai Konversi).

3

Klik Simpan

Nilai akhir tersimpan per peserta untuk putaran yang dipilih.

2

Jangan ubah kolom NRP, Nama, dan Pangkat.

3

Pilih Putaran & upload file .xlsx

Bisa ubah nama putaran saat upload (opsional). Data untuk putaran yang sama akan menimpa yang lama.

4

Cek hasil tabel

🏆 NPP

Report NPP (Angkatan)

Report NPP menampilkan hasil kompilasi seluruh angkatan: NPA, NPK, NPS, NPP, ranking, dan predikat. NPP dihitung live dari data sumber. Diakses oleh Super Admin, Opsdik, dan Kepala Sekolah.

Cara Mengatur Bobot Kompilasi

1

Pastikan semua nilai sudah diinput

NPA, NPK (minimal 1 periode), dan NPS sebaiknya sudah lengkap.

2

Buka menu Kompilasi (atur bobot)

Tersedia bagi Super Admin & Opsdik. Pilih angkatan.

3

Tentukan bobot

Contoh: Akademik 70%, Kepribadian 20%, Samapta 10%. Total harus 100%.

4

Klik "Proses Kompilasi"

Bobot tersimpan & dipakai untuk seluruh perhitungan NPP (dashboard, leaderboard, report).

5

Lihat hasil di Report NPP

Statistik: total peserta, rata-rata NPP, tertinggi/terendah. Tersedia tombol ekspor Excel.

Formula Kompilasi
NPP = (NPA × Bobot A) + (NPK × Bobot K) + (NPS × Bobot S)
Default: NPA 70% + NPK 20% + NPS 10% · Bobot dapat diubah saat kompilasi · NPK = rata-rata semua periode
✅
Live & bisa diulang: Podium, leaderboard, dan Report NPP selalu menghitung NPP secara langsung dari data terbaru. Ubah bobot kapan saja — data otomatis diperbarui tanpa duplikasi.

✍️ Penandatangan

Penandatangan

Penandatangan adalah data pejabat yang menandatangani laporan resmi. Dikelola per jenis laporan dengan cakupan bertingkat: Sekolah, Skadron (Skadik 30x), atau Global. Hanya Super Admin dan Opsdik yang bisa mengakses.

Cakupan Berlaku

CakupanKeteranganContoh Pemakaian

🛩️ Skadron / Skadik 30xSatu baris berlaku utk SEMUA sekolah under skadron tsb — cukup 4 baris utk 4 danskadik (301–304)Danskadik 301, 302, 303, 304
🌍 Global (Semua Sekolah)Berlaku utk semua sekolah jika tidak ada yang lebih spesifikKasibinjas

Jenis Penandatangan

JenisDigunakan Di
UmumFallback untuk semua laporan jika jenis spesifik belum diatur
NPA (Akademik)Laporan NPA dan Cetak Laporan
NPK (Kepribadian)Laporan NPK dan Ekspor NPK
NPS (Samapta)Laporan NPS, Cetak NPS dan Ekspor NPS
NPP (Kompilasi)Laporan NPP dan Cetak Laporan
DanskadikPenandatangan kolom kiri "Mengetahui" di SEMUA laporan — NPA, NPK, NPS, NPP (cetak & ekspor) — bukan NPP saja

Rumus & Predikat

Ringkasan semua rumus penilaian yang digunakan di SIPP.

Rumus NPA (Akademik)

Formula
NPA = Σ (Nilai × Bobot) ÷ Σ Bobot
Bobot diambil dari data Mata Pelajaran per Sekolah

Rumus NPK (Kepribadian)

Formula
NPK = 75 + Σ Poin Aspek
BS = +0.5 · B = +0.25 · C = 0 · K = -0.25 · KS = -0.5

Rumus NPS (Samapta)

Catatan
NPS = Nilai Akhir (input manual)
Versi sederhana — 5 field manual tanpa rumus otomatis. Nilai Akhir diisi langsung oleh Binjaswing.

Rumus NPP (Kompilasi)

Formula
NPP = (NPA × Bobot A%) + (NPK × Bobot K%) + (NPS × Bobot S%)
Default: NPA 70% + NPK 20% + NPS 10% · Bobot bisa diubah saat kompilasi · NPK = rata-rata semua periode

❓ FAQ

Pertanyaan Umum

Kumpulan pertanyaan yang sering ditanyakan pengguna SIPP.

Bagaimana jika lupa password?▼
Hubungi Super Admin atau Opsdik untuk reset password melalui menu Manage User.
Apa perbedaan NPA, NPK, NPS, dan NPP?▼
NPA = Nilai Prestasi Akademik (dari mata pelajaran)
NPK = Nilai Prestasi Kepribadian (dari aspek per periode)
NPS = Nilai Prestasi Samapta (5 field manual per putaran)
NPP = Nilai Prestasi Pendidikan (kompilasi NPA + NPK + NPS dengan bobot)
Apakah nilai bisa diubah setelah disimpan?▼
Ya. Setiap modul memiliki tombol Edit. Setelah diubah, nilai dan ranking otomatis terupdate karena NPP dihitung live.
Mengapa Dashboard / Leaderboard kosong?▼
Dashboard & Leaderboard kosong jika belum ada nilai yang diinput. Pastikan sudah input minimal 1 data di modul NPA, NPK, atau NPS. Podium & ranking minimal butuh 2 peserta dengan nilai.
Berapa rentang nilai NPK?▼
Minimum 70 (semua aspek KS: 75 + 10×(-0.5)) dan maksimum 80 (semua aspek BS: 75 + 10×(+0.5)).
Bagaimana cara menambah mata pelajaran?▼
Buka menu Mata Pelajaran (tersarang di bawah Report NPA). Pilih Sekolah, lalu klik "Tambah Baru" untuk mapel baru, "Petakan ke Sekolah Ini" untuk memakai mapel dari sekolah lain, "Load Template" untuk template default, atau "Duplikasi" untuk menyalin mapel dari sekolah lain.
Apakah NPS (Samapta) dihitung otomatis?▼
Tidak. Modul Samapta memakai versi sederhana: 5 field manual (Jarak Lari, Nilai Lari/Garjas A, Garjas B, Nilai Akhir, Nilai Konversi) tanpa rumus. Binjaswing mengisi Nilai Akhir secara manual per putaran.
Apa itu Putaran di modul Samapta?▼
Putaran adalah pengelompokan data NPS (mirip periode di NPK). Buat putaran baru lewat menu Tambah Putaran, lalu input data NPS untuk putaran tersebut. Data putaran yang sama akan menimpa yang lama saat diimpor ulang.
Apa itu Kompilasi dan kapan harus dilakukan?▼
Kompilasi mengatur bobot NPA+NPK+NPS yang dipakai untuk menghitung NPP. NPP sendiri selalu dihitung live di Dashboard, Leaderboard, dan Report NPP — jadi Anda tidak wajib kompilasi manual untuk melihat ranking. Ubah bobot kapan saja lewat menu Kompilasi.
Bagaimana cara cetak laporan individu?▼
Buka menu Cetak Laporan, pilih angkatan, lalu klik "🖨️ Cetak" pada peserta yang diinginkan. Gunakan Ctrl+P / Cmd+P untuk menyimpan sebagai PDF.
Apakah ada batas jumlah periode kepribadian / putaran samapta?▼
Tidak ada batas. Buat periode/putaran sebanyak yang dibutuhkan. Semua histori tersimpan dan bisa dilihat di Report NPK / Report NPS.
Bagaimana menandatangani laporan?▼
Buka menu Penandatangan. Tambahkan nama, NRP, pangkat, jabatan, jenis laporan (umum/NPA/NPK/NPS/NPP/Danskadik), dan sekolah. Penandatangan otomatis muncul di laporan cetak dan ekspor Excel.
Mengapa saya tidak bisa melihat sekolah lain?▼
Kepala Sekolah, Danflight, dan Binjaswing hanya dapat melihat sekolah yang ditugaskan saat akun dibuat. Super Admin dapat berganti skadik lewat dropdown "Pilih Skadik" di bawah sidebar. Hubungi Opsdik/Super Admin untuk menambah penugasan sekolah.
